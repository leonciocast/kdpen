# Animal silhouette sources

Every animal shape in the library is a professionally drawn silhouette
from a source that is explicitly **public domain** or **CC0**. The
downloaded SVG was normalized to a filled side/profile silhouette,
lightly closed/dilated so thin parts survive grid rasterizing, and
simplified to a single outer path.

We do **not** use Neoformix artwork, commercial puzzle-book shapes,
CC-BY, CC-BY-SA, CC-BY-NC, or any file whose license is unclear.

Original downloads are stored in `originals/`. Normalized paths used by
the app are in `svg/` and in `../animals.ts`.
