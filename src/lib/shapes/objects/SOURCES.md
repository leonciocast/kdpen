# Object, food, nature and holiday silhouette sources

These shapes are original geometric constructions drawn for this project
and then boolean-unioned into a single outer path (via `polygon-clipping`)
so a stroke never shows internal edges. Nothing is traced from commercial
puzzle books, stock art, or the reference pages used only as a style idea.

Animal silhouettes remain CC0/PD professional drawings credited in
`src/lib/shapes/animals/SOURCES.md`. Future object replacements from
PhyloPic, Openclipart CC0, or Wikimedia Public Domain should be listed
in the table below, the same way.
